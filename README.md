# Изучение языка Go (Golang)

Репозиторий содержит мой трек изучения Go, конспекты теории и код из Tour of Go.

**Шпаргалка по командам**
- `go run main.go` — скомпилировать и выполнить файл «на лету» во временной папке (без сохранения бинарника, удобно при разработке).
- `go build main.go` — скомпилировать код в самостоятельный исполняемый бинарный файл (запускается через `./main`, работает даже на машинах без установленного Go).
- `go mod init <имя>` — инициализировать Go-модуль (создать файл `go.mod`).
- `go install golang.org/x/website/tour@latest` — скачать и скомпилировать стороннюю утилиту в `~/go/bin`.
- `tour` — запустить локальный сервер учебника.

**Структура проекта**
- `01_hello/` — первая программа `Hello World`, базовая структура файла.
- `02_packages/` — работа с пакетами и генерация псевдослучайных чисел (`math/rand`).
- `03_import/` — сгруппированный импорт и форматированный вывод (`fmt.Printf`, спецификатор `%g`).
- `04_exported_names/` — инкапсуляция и доступ к публичным константам (`math.Pi`).
- `05_functions/` — объявление функций, передача параметров и сокращенная запись типов.
- `06_multiple_results/` — возврат нескольких значений из функции и краткое объявление `:=`.

**Теоретический минимум (Занятие 1)**
- **Архитектура пакетов:** Физически пакет — это одна папка. Все файлы `.go` внутри одной директории обязаны иметь одинаковое имя пакета и видят код друг друга без импортов.
- **Исключение `package main`:** Имя пакета должно совпадать с именем папки всегда, кроме случая, когда мы пишем исполняемую программу. `package main` говорит компилятору собрать исполняемый бинарник с точкой входа `func main()`, а не библиотеку. В одном пакете может быть только одна функция `main()`.
- **Импорт пакетов:** Аналог `#include` из C — блок `import (...)`. Путь указывается относительно корня библиотеки (например, `"math/rand"`), а в коде обращение идет по последнему элементу пути (`rand.Intn`).
- **Экспорт (Инкапсуляция):** Вместо ключевых слов `public` и `private` используется регистр первой буквы. Имена с **Заглавной** буквы (`math.Pi`, `fmt.Println`) публичны и доступны из других пакетов; со **строчной** — приватны внутри своего пакета.
- **Синтаксис и типы:** Открывающая скобка `{` строго обязана стоять на той же строке, что и объявление. Тип переменной указывается *после* её имени (`x int`), чтобы объявления читались слева направо. Если подряд идут параметры одного типа, тип пишется только у последнего (`x, y int`).
- **Множественный возврат:** Функция может возвращать сразу несколько значений — их типы перечисляются в скобках перед телом функции: `func swap(x, y string) (string, string)`.
- **Оператор `:=`:** Краткое объявление переменной (`a, b := swap(...)`). Создает новую переменную и автоматически выводит её тип из правой части. Работает **только внутри функций**; повторно объявлять через `:=` уже существующую переменную нельзя (кроме множественного присваивания, где хотя бы одна переменная слева — новая).
- **Форматированный вывод (`%g` vs `%f`):** В `fmt.Printf` спецификатор `%f` жестко печатает 6 знаков после запятой (добивая нулями), а умный формат `%g` отсекает незначащие нули на конце и автоматически переходит в научную нотацию (`%e`) на слишком больших или малых числах.
- **Go Playground:** Серверы песочницы замораживают время (10.11.2009) и генераторы случайных чисел для кэширования вывода.
