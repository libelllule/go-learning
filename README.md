# Изучение языка Go (Golang)

Репозиторий содержит мой трек изучения Go, конспекты теории и код из Tour of Go.

**Шпаргалка по командам**
* `go run main.go` — скомпилировать и выполнить файл «на лету» (без сохранения бинарника).
* `go mod init <имя>` — инициализировать Go-модуль (создать файл go.mod).
* `go install golang.org/x/website/tour@latest` — скачать стороннюю программу (Tour of Go).
* `tour` — запустить локальный сервер учебника.

**Структура проекта**
* `01_hello/` — первая программа `Hello World`, разбор структуры файла.

**Теоретический минимум (Занятие 1)**
* **Импорт пакетов:** В Go нет заголовочных файлов. Аналог `#include <stdio.h>` из C — это `import "fmt"`. В коде функции вызываются по короткому имени пакета (`fmt.Println`).
* **Экспорт интерфейсов:** Если имя функции или переменной начинается с **Заглавной** буквы, оно экспортируется (становится публичным для других пакетов).
* **Синтаксис:** Открывающая фигурная скобка `{` строго обязана стоять на той же строке, что и объявление функции.
* **Go Playground:** Серверы Google жестко замораживают время (10.11.2009) и генераторы случайных чисел, чтобы закэшировать вывод программы и не компилировать одинаковый код повторно.
