# Проникновение Аннален (Annalyn's Infiltration)

Добро пожаловать в задачу «Проникновение Аннален» трека Go на Exercism.
Если вам нужна помощь с запуском тестов или отправкой решения, ознакомьтесь с файлом `HELP.md`.
Если вы застряли при решении, загляните в `HINTS.md`, но сначала попробуйте решить задачу самостоятельно :)

## Введение

Логические значения (булевы) в Go представлены встроенным типом `bool`, значениями которого могут быть либо `true` (истина), либо `false` (ложь).
Это строго определённый тип.

```go
var closed bool    // булева переменная 'closed' по умолчанию инициализируется значением 'false'
speeding := true   // булева переменная 'speeding' инициализирована значением 'true'
hasError := false  // булева переменная 'hasError' инициализирована значением 'false' 
```

Go поддерживает три логических оператора, которые вычисляют выражения до логического значения и возвращают `true` или `false`.

| Оператор    | Что означает                                        |
| ----------- | --------------------------------------------------- |
| `&&` (и)    | Возвращает `true`, если оба утверждения истинны.    |
| `\|\|` (или)| Возвращает `true`, если хотя бы одно утверждение истинно. |
| `!` (не)    | Возвращает `true`, только если утверждение ложно.   |

## Инструкция

В этом упражнении вам предстоит реализовать логику квеста для новой RPG-игры, которую разрабатывает ваш друг.
Главная героиня игры — Аннален (Annalyn), храбрая девушка с преданным и свирепым ручным псом.
К несчастью, случается беда: её лучшего друга похитили, пока он собирал ягоды в лесу.
Аннален собирается найти и освободить лучшего друга, при желании взяв с собой в этот поход собаку.

Потратив некоторое время на поиски по следам друга, она находит лагерь похитителей, в котором заточен её друг.
Оказывается, похитителей двое: могучий рыцарь и коварный лучник.

Обнаружив похитителей, Аннален обдумывает, какие из следующих действий она может совершить:

- _Быстрая атака (Fast attack)_: быструю атаку можно совершить, если рыцарь спит, так как ему требуется время, чтобы надеть доспехи, и он будет уязвим.
- _Шпионаж (Spy)_: шпионить за лагерем можно, если хотя бы один из похитителей или пленник бодрствует. В противном случае шпионить — пустая трата времени.
- _Подать сигнал пленнику (Signal prisoner)_: пленнику можно подать сигнал звуками птиц, если пленник бодрствует, а лучник спит (лучники обучены распознавать птичьи сигналы и могут перехватить сообщение).
- _Освободить пленника (Free prisoner)_: Аннален может попытаться прокрасться в лагерь, чтобы освободить друга. Это рискованное действие, и оно может увенчаться успехом только в одном из двух случаев:
  - Если с Аннален её собака: она может спасти пленника, если лучник спит. Рыцарь боится собаки, а лучник не успеет изготовиться к стрельбе до того, как Аннален и пленник сбегут.
  - Если собаки с ней нет: Аннален и пленник должны действовать очень скрытно! Аннален может освободить пленника, если пленник бодрствует, а рыцарь и лучник оба спят. Но если пленник спит, спасти его нельзя: внезапное появление Аннален напугает его, и он разбудит рыцаря и лучника.

Перед вами стоят четыре задачи: реализовать логику для определения доступности каждого из этих действий на основе состояния трех персонажей в лесу и присутствия собаки Аннален.

## 1. Проверить, можно ли совершить быструю атаку

Определите функцию `CanFastAttack()`, которая принимает булево значение, указывающее, бодрствует ли рыцарь.
Функция возвращает `true`, если быстрая атака возможна на основе состояния рыцаря.
В противном случае возвращает `false`:

```go
var knightIsAwake = true
fmt.Println(CanFastAttack(knightIsAwake))
// Вывод: false
```

## 2. Проверить, можно ли шпионить за лагерем

Определите функцию `CanSpy()`, которая принимает три булевых значения, указывающих, бодрствуют ли рыцарь, лучник и пленник соответственно.
Функция возвращает `true`, если за лагерем можно шпионить, на основе состояния трех персонажей.
В противном случае возвращает `false`:

```go
var knightIsAwake = false
var archerIsAwake = true
var prisonerIsAwake = false
fmt.Println(CanSpy(knightIsAwake, archerIsAwake, prisonerIsAwake))
// Вывод: true
```

## 3. Проверить, можно ли подать сигнал пленнику

Определите функцию `CanSignalPrisoner()`, которая принимает два булевых значения, указывающих, бодрствуют ли лучник и пленник соответственно.
Функция возвращает `true`, если пленнику можно подать сигнал, на основе состояния этих двух персонажей.
В противном случае возвращает `false`:

```go
var archerIsAwake = false
var prisonerIsAwake = true
fmt.Println(CanSignalPrisoner(archerIsAwake, prisonerIsAwake))
// Вывод: true
```

## 4. Проверить, можно ли освободить пленника

Определите функцию `CanFreePrisoner()`, которая принимает четыре булевых значения.
Первые три параметра указывают, бодрствуют ли рыцарь, лучник и пленник соответственно.
Последний параметр указывает, находится ли рядом ручной пёс Аннален.
Функция возвращает `true`, если пленника можно освободить, исходя из состояния трех персонажей и присутствия собаки.
В противном случае возвращает `false`:

```go
var knightIsAwake = false
var archerIsAwake = true
var prisonerIsAwake = false
var petDogIsPresent = false
fmt.Println(CanFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent))
// Вывод: false
```
