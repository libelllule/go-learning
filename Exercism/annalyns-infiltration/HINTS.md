# Подсказки

## Общие

- Для работы с логическими значениями существуют три [логических оператора][logical operators].
- В одном выражении можно комбинировать несколько операторов.

## 1. Проверка возможности быстрой атаки

- Оператор логического НЕ (`!`) ставится перед выражением, чтобы инвертировать его значение.

## 2. Проверка возможности шпионажа

- Логические операторы обычно используются для проверки того, являются ли два или более выражения истинными или ложными.

## 3. Проверка возможности подать сигнал пленнику

- Логические операторы выполняются в порядке их приоритета (от высшего к низшему): `!`, `&&`, `||`.
- Подробнее см. раздел о приоритете операторов в [официальной документации Go][operators] и статью о [таблицах истинности][truth table].
