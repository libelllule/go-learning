# Справка

## Запуск тестов

Чтобы запустить тесты, выполните команду `go test` в каталоге с упражнением.

Если набор тестов содержит бенчмарки, вы можете запустить их с флагами `--bench` и `--benchmem`:

    go test -v --bench . --benchmem

Имейте в виду, что каждый проверяющий запускает бенчмарки на своей машине с разными характеристиками, поэтому результаты тестов производительности могут различаться.

## Отправка решения

Вы можете отправить свое решение с помощью команды:
```bash
exercism submit annalyns_infiltration.go
```
Эта команда загрузит ваше решение на сайт Exercism и выведет ссылку на страницу с решением.

Можно отправлять даже незавершённое решение — это позволит вам:

- Посмотреть, как выполнили задание другие участники
- Попросить помощи у ментора
